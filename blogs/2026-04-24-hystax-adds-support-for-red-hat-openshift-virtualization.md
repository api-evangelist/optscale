Red Hat OpenShift Virtualization is becoming an increasingly common choice for organizations that want to run virtual machines (VMs) alongside containerized workloads within a unified Kubernetes-based platform. Hystax Acura now supports Red Hat OpenShift Virtualization, extending its migration, disaster recovery, and backup capabilities to Red Hat OpenShift-based infrastructure, and is also represented in the Red Hat Ecosystem Catalog.
