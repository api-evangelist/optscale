An immutable backup is a copy of data that cannot be altered, encrypted, or deleted for a set retention period – even by an administrator or ransomware. This guide explains how WORM storage and Object Lock work, compares governance and compliance modes, and shows how to build an immutable backup architecture for KVM, OpenStack, oVirt, and other virtual environments.
